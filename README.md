# Парсер списка криптовалют с Etherscan

Небольшой учебный проект по парсингу HTML с помощью `BeautifulSoup`.  
Программа собирает список токенов с публичной страницы Etherscan и выводит
их в отсортированном виде.

Источник данных:

- Онлайн-страница: <https://etherscan.io/tokens>
- Либо заранее скачанный HTML-файл этой страницы (например, `tokens.html`)

## Что делает программа

- Загружает HTML-страницу со списком токенов (из интернета или локального файла).
- Извлекает для каждого токена:
  - название и тикер (например: `Tether USD (USDT)`);
  - цену в USD, приведённую к числу (`float`);
  - ссылку на страницу токена на Etherscan.
- Сортирует токены **по убыванию цены** (самые дорогие сверху).
- Выводит на экран указанное пользователем количество записей.

Установка
Требуется Python 3.8+.

Клонировать репозиторий:

bash
Копировать код
git clone <ссылка-на-репозиторий>
cd <папка-репозитория>
(Рекомендуется) создать виртуальное окружение:

bash
Копировать код
python -m venv venv
# Linux / macOS:
source venv/bin/activate
# Windows:
venv\Scripts\activate
Установить зависимости:

bash
Копировать код
pip install -r requirements.txt
Запуск
Вариант 1 — страница скачивается автоматически
bash
Копировать код
python parse_crypto.py -n 10
Где:

-n 10 — вывести 10 самых дорогих токенов.

Если -n не указать, по умолчанию будет выведено 10 записей.

Вариант 2 — использовать заранее скачанный HTML-файл
Сначала в браузере сохраните страницу https://etherscan.io/tokens как tokens.html
(полная HTML-страница).

Затем:

bash
Копировать код
python parse_crypto.py --html-file tokens.html -n 20
Параметры:

--html-file tokens.html — путь к локальному файлу с HTML.

-n 20 — вывести 20 строк.

Примеры
bash
Копировать код
# 5 самых дорогих токенов, страница скачивается из интернета
python parse_crypto.py -n 5

# Все токены, используя локальный файл
python parse_crypto.py --html-file tokens.html

# 15 токенов из локального файла
python parse_crypto.py --html-file tokens.html -n 15
